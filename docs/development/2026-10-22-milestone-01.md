# 里程碑 1 开发日志

日期：2026-10-22（北京时间）。

## 本次子阶段：数据重建与预测基线

本次范围为监督预测基础；单热区仿真、动态模型、规则控制与 MPC 尚未开始，不能据此将整个里程碑 1 标记完成。

### 目标与验收

1. 不修改历史原始资产，重新核对标签、单位、缺失值与数据来源。
2. 可复现旧清洗产物；构建标签含义正确、来源隔离的主评测和外部气候测试。
3. 运行均值、线性、树模型、旧网络结构、冷热偏好与 PMV 基线，保留指标与模型。
4. 验证随机种子、切分隔离、保存后重载和旧过滤规则影响。
5. 归档紧凑结果，更新总项目文档并同步 GitHub `main`。

### 数据与协议决定

- 原始表 107,584 行；四输入完整 71,429 行。主评测室温质控沿用上游 `10 < ta < 40°C`，排除 217 条完整输入记录。旧流程复现不应用这项新规则。
- 旧预处理逐值匹配现存 CSV：完整热感觉记录 71,177，温度—标签规则删除 8,763，再删除 1,715 条非整数记录，保留 60,699。
- 主热感觉任务保留 −3～3 及小数标签。冷热偏好映射为 0/1/2，不混用主观舒适度。

- 固定来源组切分与种子 33；五个训练种子为 33～37。输入缩放器仅拟合训练集，神经网络仅按验证集选择权重。

### 发现的问题与处理

- 第一轮准备因缺失来源而停止：将缺失来源合并为同一组，不按行生成虚假独立来源，随后隔离测试通过。
- Numba 的依赖约束要求降低继承环境中的 NumPy 版本：项目环境固定 NumPy 2.3.5，并验证 PMV 与 PyTorch 同时可用。
- 继承环境的 `pip check` 发现项目之外的 inscriptis/lxml 版本冲突。未修改全局安装，另建独立 CPU 环境完成干净安装和依赖检查。
- PMV 默认适用范围会排除部分相对风速、动态衣着、蒸汽压和 PMV 超限记录：保留限制与 NaN，另存覆盖率及警告摘要，不填入假定输入或关闭范围检查。
- 上游资料浏览的部分历史下载链接返回 403，改用官方维护仓库固定提交和 Dryad 元数据 API 核查；本地快照准确发行版仍未确定，不虚填版本号。

### 阶段结果与下一步

| 方法 | 来源分组测试 RMSE | Cfa 外部测试 RMSE |
| --- | ---: | ---: |
| 训练均值 | 1.1501 | 1.1736 |
| 线性回归 | 1.0337 | 1.0661 |
| 随机森林（五种子） | 1.1137 ± 0.0012 | 1.1113 ± 0.0008 |
| 旧网络结构（五种子） | 1.0312 ± 0.0175 | 1.0759 ± 0.0075 |

± 是训练种子间标准差，不是跨建筑置信区间。旧网络没有显示相对线性模型的稳定优势，应继续保留简单基线。

冷热偏好随机森林 Macro-F1 为 0.4522 ± 0.0039（测试）和 0.3854 ± 0.0037（外部）；线性分类的部分概率质量指标更好，不能仅按分类 F1 决定控制评分器。

固定种子随机森林在同一主测试集的 RMSE 为 1.1142；仅将测试人群改成旧过滤保留样本，就降至 0.9658。旧过滤训练模型在未过滤测试集反而为 1.2091，在过滤测试集为 0.9356。这说明过滤与评测人群必须分开报告。

PMV 与六输入模型在共同测试子集比较，覆盖主测试 1,464/7,388 行、外部测试 1,782/12,874 行。不能将这些分数与全样本四输入结果直接排名。

本次子阶段完成。下一步为 BOPTEST 单热区环境与规则控制数据采集；先使用明确温度约束，保留偏好模型作为待继续验证的评分器。本次不报告控制节能或真实 Sim-to-Real 成功。
