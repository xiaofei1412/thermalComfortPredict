# 阶段开发日志

| 阶段 | 日志 | 状态 |
| --- | --- | --- |
| 里程碑 1 | [2026-10-22](2026-10-22-milestone-01.md) | 舒适恢复、空载耗电与天气误差对照完成；暖工况可靠性与人员需求接入待完善 |

## 文件约定

- 文件名使用 `YYYY-MM-DD-milestone-NN.md`，日期为阶段开始日期，使用北京时间。
- 同一阶段持续更新同一文件；阶段编号与根目录 `PROJECT.md` 对应。
- 根目录 `PROJECT.md` 简要保留阶段结果并链接详细日志。

## 每份日志的内容

1. 目标与验收标准。
2. 主要变更与相关文件。
3. 实际执行的验证命令、结果与失败项。
4. 阶段结论、已知限制和未完成事项。
5. 下一步。

只记录实际发生的开发与验证，不将预期效果写为实验结果。
