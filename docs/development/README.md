## 文件约定

- 文件名使用 `YYYY-MM-DD-milestone-NN.md`，日期为阶段开始日期，使用北京时间。
- 同一阶段持续更新同一文件；阶段编号与根目录 `PROJECT.md` 对应。
- 根目录 `PROJECT.md` 简要保留阶段结果并链接详细日志。

## 每份日志的内容

1. 目标与验收标准。
2. 主要变更与相关文件。
3. 实际执行的验证命令、结果与失败项。
4. 阶段结论、已知限制和未完成事项。
5. 下一步。
6. 对根目录`ROADMAP.md`的影响：对应步骤、状态、证据、新补项及依赖变化；无补项也记录计划不变，并同步计划变更记录。

只记录实际发生的开发与验证，不将预期效果写为实验结果。
