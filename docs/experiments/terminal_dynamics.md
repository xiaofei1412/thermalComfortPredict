# 冷暖季末端动态、未触碰校准与新气候场景

## 预先固定的范围

以`11a704e`为基线，旧住宅与办公室源码/模型保持冻结。只用新丹佛办公室回合开发，在从未运行的**同一48 m²办公室＋布鲁塞尔TMY天气**组合测试；这不是新气象年度或新建筑实体。固定BOPTEST 0.9.0及上游`9b1610bf7a108826bb3d22c72bffd2d71d7bb0a9`。天气场景只替换FMU气象mos、预报weather.csv和案例名，二进制、围护结构、末端、内部得热与占用日程不变；检验两套实际/预报天气一起替换及地理/太阳几何一致。

每回合包含6天内置预热＋1天22°C共同预序列。开发角色与每回合连同预热均无交叠，也避开所有旧**丹佛办公室**训练/选模/标定/响应/测试窗口。角色在一年内按季节交错，是时间分块隔离，不称全年训练先于校准的未来时间留出。正式泛化对象是未用过的办公室气候组合；布鲁塞尔天气曾用于住宅，不能称气象文件本身从未见过。旧测试、旧21天目标数据不用于拟合、选模、定裕量或控制开发。

采集使用固定种子、1/2/4/8步变长激励和0.5K/步限速；动作18～23.25°C，空气温度低于20°C强制恢复，超过官方上界−0.2K停止供暖，18～35°C中止带保持。输出30秒原生信号，分别保存区间平均与末端瞬时供热、供冷、风机功率，不能把两者混作同一状态。开发18天、校准9天；闭环开发/干预和复跑另计，不宣传只用少量拟合天数。

## 模型、选择和锁定顺序

保留空气/蓄热热网络＋残差，物理效率0.9、冷却COP3来自已知FMU。比较同一12天数据重拟合的静态末端和**区间平均/端点分离的动态末端**：使用当前估计温度、已发生的端点HVAC、当前动作/动作变化、已知冷却日程预测区间平均量与下一端点，独立学习风机平均/端点映射。所有能源非负有界；未来实际温度/HVAC/内部PI状态禁止回填。旧3天模型作为外部基线。

两模型各用残差权重0/1；热网络/末端/残差只拟合训练角色。选模指标固定为两个选模回合上1/6小时空气温度RMSE均值（以1K归一）＋6小时燃气RMSE与6小时冷却电量RMSE之和（各以1kWh归一），两个季节等权。报告全部候选和原基线，不看正式测试改选。选择集可用于开发诊断与临时裕量，不能冒充独立校准。

开发初版多系数自回归端点模型未胜过静态模型，源码/模型和开发轨迹保留。校准前替换为较简单的一阶滞后：目标功率由静态投影、偏置、当前动作变化给出，区间平均和端点均为目标/上一端点的凸组合，时间常数10～1800秒，避免自由自回归增益叠加；四个参数分别拟合供暖和制冷的训练平均/端点读数。选模评分、校准算法与正式测试计划不变。未胜出的复杂动态候选不强行部署。

选模日62/150另运行两档20.5/23.25°C半天成对干预，前16步22°C共同动作，随后32步固定档位并限速，共2天额外开发轨迹。报告1/4/24/32步温差、燃气、冷却电量响应与幅度误差；只在实测首小时燃气差>0.001kWh的有激励分支检查温度/燃气方向，未激励分支单列，至少一支有激励且方向通过。长时混合制冷的温度不要求单调；不以此作为反事实准确性证书。

**先生成development_lock.json，后生成校准数据。** 锁绑定模型、配置、协议、采集策略、控制/工况/标定核心源码和选模结果。锁前校准输出必须不存在；校准采集每支前核验锁，最终权重不重训。标定程序只输出独立margins.json，不改模型权重；校准后不按覆盖或可行率调整算法、门槛、模型或控制。任何修订都需明确新一轮开发及新的未触碰校准，不能静默重用。

## 工况与裕量

每个预测起点/步长仅用当时信息分组：若预测窗内公开冷却设定发生变化则transition；否则依最近已发生端点功率，以0.01kW区分heating/cooling（同时活动归transition），均不活动为idle。不得按未来实际冷热量、未来越界或预测误差大小分组。

每工况、每步分别标定下/上侧温差：`max(0, q95(predicted−actual))+0.1K`和`max(0,q95(actual−predicted))+0.1K`。少于20个起点的格子使用同一步长的全校准池，显式保存计数与回退标志；不通过裁小裕量强造可行性。经验单侧95%不是双侧95%、整段联合覆盖或概率安全保证；重叠起点也非独立样本。完整校准9天一次性使用后公开全工况覆盖和数量，不以测试误差回调。

## MPC、公平性与验收

仍只覆盖供暖设定值，内置冷却、风机、送风不覆盖。三策略统一前16步规则初始化以匹配离线预测起点；旧模型权重/原裕量保持，旧策略只做这一共同初始化适配。新策略6小时候选动作/8小时参照，限制温度/蓄热不高于同模型规则参照、分能源不高于规则参照；无支持、收紧带为空、无可行计划均回退。按**限速后的**规则动作区分计划和实际动作差异，不夸大接管。

校准后检查空收紧带、支持拒绝、候选可行数和原因，不依据这些计数继续开发。冻结模型、锁、校准摘要/裕量、参数与场景FMU后测试；完美/6小时渐变±2K/±25%合成天气偏置只影响预报视图。沿用1e-6验收：严格少电，冷热越界积分、时长和最大偏差不增，燃气与总终端能量不增。分别对规则、旧办公室模型报告；保留所有失败，不能靠冷热抵消或能源转移通过。

开发旧模型在day62触发18°C中止带，保留截断轨迹和失败原因，不改旧模型、不把截断累计量当完整回合。训练/选模/校准数据必须完整；只允许评估角色读取部分轨迹。正式旧基线若中止，该成对验收记未通过，规则对新策略的验收仍独立判断。独立前缀重复长度为完整轨迹与24步的较小值，若原轨迹更早中止则要求复现相同中止，不强称重复满6小时。

核验新旧数据隔离、锁先于校准、模型独立重训、全部原生KPI/决策、共同初始化与规则天气不变性、27支首6小时独立重复；不声称整段七天重复。预测1/4/24/32步温度、燃气、冷却/风机电量及分工况上下侧覆盖，未来记录动作只作条件输入。完整工件`outputs/terminal-*`，紧凑报告`reports/terminal_dynamics`；本轮没有真实楼宇或Sim-to-Real证据。
