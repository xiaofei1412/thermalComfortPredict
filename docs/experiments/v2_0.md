## 信息权限与回合定义

- 原MPC名义优化24步/6小时，提前停热投影32步/8小时，参考轨迹末步再读4小时日程，构造器请求48步/12小时。V2共同权限固定当前至+12小时的49个900秒样本，7个外生字段见机器协议；不能向RL暴露旧采集器预取的整段7天预报。评分仍保留原生30秒外生/轨迹，不以降采样替代积分。
- 只用当前操作温度、当前/前次实际设定、当前热/电功率、已结束区间供热均值、时钟/剩余步数，以及相同合法预报；不提供真实蓄热隐状态、未来温度/功率/能耗。最多16步已发生历史；启动时只用已观察值及padding mask，不能从不可见预热轨迹或未来补齐。
- 7天有限回合须显式提供剩余步数；成功到达定义的回合末端和外部训练限额/基础设施截断分别处理，细节在V2-1接口回归中固定。公共启动段完整计分但不冒充RL动作；同一算法检查点的统计量在评估中不更新。
- 连续RL动作归一化为[-1,1]，表示相对前次设定的±0.5K建议变化，经同一限幅/限速得到实际动作；保存建议、实际下发及回退。MPC自有候选网格/模型结构属于算法差异，不因此给它或RL更宽机械范围。
- 偏差模式沿用原函数实际行为：温度±2K、太阳±25%，按`min(lead/21600,1)`渐变；lead0不变。旧函数注释写2小时，但solar配置实际是6小时，本轮登记实际行为，不修改冻结源码。完美预报作为主表，偏差两模式作为同环境压力表，全部在最终评估前冻结。
- 末端操作温度/回水/供水/供热状态另报，显著终态差异要讨论蓄热消耗；7天结果不外推连续全年或循环稳态节能。如开发中需终端恢复尾段，必须先升级协议和重新校验保护窗口，不能在留出后追加有利口径。

## 比较门与尚未锁定的训练预算

以下为本协议在V2控制结果出现前登记的比较口径；若数值回归表明不能用于新接口，只能在学习前升级协议、保留旧版及理由，不得在看到留出后修改。

- 分别对规则与MPC逐天气/日期、逐种子比较。主能耗组由冻结规则7天电量≥1kWh定义，不能按RL表现筛选；每个登记种子均须节电≥2%且≥0.1kWh，并同时满足全部温度门。只胜规则不胜MPC不能叫超越第一代最优方案；无足够主能耗组不形成节电资格。
- 过冷/过热K·h分别不增加（数值容差1e-6），各自时长不增加（1e-6秒浮点容差），最大偏差不增加（1e-5K）。同时报告全部原值与差值，不把误差容差解释为可牺牲舒适度。
- 规则电量<1kWh的低/零负荷组完整列出，RL电量允许数值/待机差≤0.01kWh、温度门仍须通过，不报不稳定的节电百分比。供暖无法主动制冷的过热不藏于总体平均。
- 机械违反0、中止/不完整回合不能过门；额外RL回退≤20%（不含共同8步启动），若主要由规则接管，只报组合策略，不宣称纯RL控制收益。
- 固定训练种子11/23/37，每算法最多2套开发配置；报告全部种子/日期与成对差异，不选最好种子。该门不是统计显著性证明，置信区间与少量天气块限制单列。

训练奖励权重、折扣、交互/墙钟上限及完整学习配置**仍未授权/未冻结**，不得启动学习。V2-1先只在train014工程窗口实现/验证接口和测成本，V2-2只在开发窗口做基线/动作响应；两阶段通过后用独立的子协议/学习锁引用本v1 SHA补充预算和奖励，不能直接覆写这份V2-0锁。V2-3/4仅训练/开发角色可用，V2-5才生成留出/历史回归轨迹。
