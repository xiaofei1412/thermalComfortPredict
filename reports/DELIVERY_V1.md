# 智慧楼宇环境预测与控制研究：第一版交付报告

日期：2026-10-26

## 1. 目标与条件

项目由旧热舒适预测实验重建，目标是在缺少实验室硬件、原始项目数据不完整的条件下，建立可复核的楼宇环境预测与控制流程，兼顾研究和作品展示。第一版以公开数据和软件仿真为基础。

## 2. 做了什么，为什么这样做

| 已完成工作 | 原因 |
| --- | --- |
| 整理旧代码，重建热感觉、冷热偏好预测基线 | 保留历史成果，同时分清不同预测目标，让旧项目有可信起点。 |
| 搭建BOPTEST单热区仿真，运行规则控制并采集轨迹 | 没有真实设备时，用可重复的软件环境验证动作、温度和能耗之间的关系。 |
| 建立热阻—热容灰箱、学习残差和温度/功率多步预测模型 | 静态预测不足以支持控制，需要预测“改变动作后会怎样”，并约束负耗电等不合理输出。 |
| 实现短时域MPC、误差裕量及规则回退，开展公平对照 | 检查能否在温度越界不增加的条件下节能，同时保留模型失准时的回退方式。 |
| 开展跨天气、跨建筑和少样本适配，并诊断PI状态、风量与末端功率 | 检查单一场景的成功是否可迁移，定位误差来源，避免只凭温度预测较准就升级控制。 |
| 保留时间隔离、版本冻结、阶段日志和自动检查 | 防止测试数据参与调参，让成功、失败和适用边界都可追溯。 |

## 3. 结果与交付边界

**住宅有限仿真留出取得了正结果。** 同一住宅的9组对照节电约1.62%～9.49%，温度越界未增加，但仍有过热场景，不能推广为所有楼宇都有效。见[住宅报告](solar_mpc/REPORT.md)。

**办公室迁移尚未达到控制升级要求。** 最终候选通过60/72项开发门和2/2项动作响应，仍有长时能源、温度误差及供暖覆盖不足。按预设停止条件封存负结果，本轮不开展新校准或盲评，维持规则控制。见[最终报告](office_final_round/REPORT.md)与[适用边界](office_final_round/BOUNDARY.md)。

第一版交付包括代码、实验配置、验证记录、阶段日志和紧凑报告；大型轨迹与模型保留在本地`outputs/`，未加入Git。现有122项测试通过，支持实现核验，不代表全部研究目标已经达成。

当前是软件仿真研究原型：人员需求预测器尚未接入控制，尚未形成与真实建筑同步的数字孪生，也未完成真实楼宇闭环、Sim-to-Real或具身智能验证。

## 4. 后续可拓展与优化

- **先完善交付和人员需求接入。** 统一运行入口、结果可视化和演示；探索如何将热感觉、冷热偏好转为可解释的控制目标，保留它们与空气温度指标的区别。
- **再研究数据覆盖与模型可靠性。** 在新协议下补足工况，利用公开楼宇数据做离线验证，重点检查长时能源偏差、状态估计和不确定性，而不只追求平均温度误差下降。
- **有明确适用范围后再扩算法和场景。** 可考虑稳健MPC与学习控制/RL对照、多区域模型，以及模拟中的主动感知；世界模型方向应先验证动作响应与长时滚动能力。

这些是后续候选方向，不在本次交付中自动执行。若重启办公室迁移，需另立问题、数据角色和实验协议，保留本次负结果，不能继续调旧测试后称为盲评。
