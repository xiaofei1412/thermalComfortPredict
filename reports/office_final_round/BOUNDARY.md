# 本轮办公室适用边界

状态：**closed_negative；本轮迁移攻关结束。**

| 范围 | 已有证据 | 可作的表述 |
| --- | --- | --- |
| 对象 | BOPTEST 0.9.0单热区48m² bestest_air，固定天气/围护/日程 | 仿真办公室研究，未代表所有办公室 |
| 温度目标 | 区域空气温度与官方上下界 | 不等于操作温度、个人热感觉或热舒适标签 |
| 末端和能源 | 已知源PI、二阶风量；燃气供暖、电制冷和风机 | 不能外推热泵、其他末端/能源或未知真实控制器 |
| 控制接口 | 只覆盖供暖设定值，内置冷却/风机/送风不覆盖 | 没有验证联合冷热末端控制能力 |
| 模型信息 | 过去温度/功率、公开初始风量、历史动作；未来动作/外生量作条件输入 | 可复现离线条件预测；不等于自主预测未来动作 |
| 源结构先验 | PI k/Ti/Ni、风量极点来自编译FMU | 不是从真实楼宇数据独立辨识出的内部参数 |
| 数据 | 既有12天训练、两日期规则/激励开发、有限高低档干预 | 没有新的未见建筑/气候泛化成绩 |
| 短时能力 | 24/24端点功率门、2/2响应门通过 | 部分开发能力成立，不能代替整体控制资格 |
| 长时能力 | 9项累计能源和1项温度门失败 | 不具备全部开发工况可靠优化预测能力 |
| 覆盖 | 暖季供暖活动起点2/0，要求10 | 此工况证据不足，不能当成零耗气预测成功 |
| 控制结论 | 整体门未过，未运行新校准/盲评 | 不宣称本轮实现节能且温度越界不增 |
| 真实迁移 | 没有真实数据离线迁移或真实楼宇闭环 | 不宣称已完成Sim-to-Real |

本轮模型可作为固定仿真接口内的离线研究与方法展示工件。没有任何“允许替代规则控制”的部署范围，也不因为冷季燃气等分项通过而单独放行控制。

维持规则控制是当前基线选择；规则已有开发过热，不能解释为全工况舒适保证。旧住宅有限成功、旧办公室迁移/校准失败和本次有限修复结果分别保留，不能把住宅结果扩大为办公室结论。

停止决定不证明办公室迁移在理论上不可能，只说明**此数据、模型、接口与预算下没有达到预设资格**。今后若重启，需要新的研究协议；本次负结果和旧测试不覆盖、不回调。
